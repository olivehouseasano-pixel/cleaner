キッチン換気扇部品の浸け置き洗浄例(洗浄中)

実際の使用例です。汚れの種類・程度・素材等により結果は異なります。

⚠ まぜるな危険(塩素系)

酸性洗剤や漂白剤等の薬剤と混合すると有害な塩素ガスが発生するため、同時使用は絶対にしないでください。他の薬品・洗浄剤とも混ぜないでください。

濡れた手で粉末に直接触れないでください(火傷の危険性があります)。

動物や食品の除菌洗浄には使用しないでください。

基本使用方法

  • 大容量:40〜60℃のお湯10Lに30g(頑固な汚れには100g)
  • 少量:40〜60℃のお湯500mlに5g
  • 洗浄水を対象部分へ散布し、通常2〜3分程度置きます(ひどい汚れの場合は10分程度)
  • ブラシ等で擦り洗い、または漬け込み洗いをします
  • 作り置きすると洗浄水の成分が失活するため、使い切りを推奨します

使用時のポイント

  • キッチンまわりの頑固な油汚れなどに使用できます。
  • 拭き掃除・浸け置きでご使用ください。
  • 素材への影響が気になる場合は、目立たない場所で確認してからご使用ください。

使用後の処理

使用後は十分に水洗いし、乾燥させてください。

他の薬品や洗浄剤と混ぜないでください。

目や粘膜に付着した場合は直ちに水で15〜30分洗い流し、使用中に異常を感じた場合はただちに使用を中止し、医師の診断を受けてください。

基本使用方法

  • 使用前によく振ります
  • ロックをON側にします
  • ニオイが気になる場所から20〜30cm離し、表面全体が軽く湿る程度にスプレーします
  • スプレー後は自然乾燥させます(拭き取り不要)

使用時のポイント

  • 布・靴・プラスチック・ゴミ箱等に直接散布して使用できます。
  • 臭いの元を取り除いたうえでご使用ください。
  • 生肉やたばこの臭いには不向きです。

使用後の処理

使用後はロックして立てて保管してください。開封後は湿気を避け、安全な場所に保管してください。
